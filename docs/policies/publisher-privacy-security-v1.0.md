# Publisher Privacy and Security Requirements — Version 1.0

Status: engineering publication candidate. Effective only after privacy and security approval.

Publishers must minimize collection, document purpose and retention, isolate each school, encrypt data in transit and at rest where applicable, avoid secrets in packages/logs, and support access, correction, export, deletion, and incident investigation. Student, grade, attendance, fee, health, location, and communication data are confidential school data and may not be used for advertising or unrelated model training.

Security reports must be acknowledged within one business day for critical/high severity and three business days otherwise. A suspected compromise must be reported immediately with affected versions, indicators, mitigations, and a communication contact. Signing keys require MFA-protected membership, independent approval, rotation, revocation, and an offline recovery record. Publishers must retain build provenance, dependency inventory, test results, and release source sufficient to reproduce review evidence.
