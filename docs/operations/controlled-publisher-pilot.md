# Controlled Publisher Pilot

Publishing remains invitation-only. Public self-service is disabled.

Invite 3–5 publishers representing different plugin risks and submit 5–10 plugins. Every publisher completes verified email, MFA, organization dual verification, all current policy acceptances, two-person key enrollment, and support/finance contacts. The pilot must include one update, one rejection, one signing-key rotation, one vulnerability withdrawal/advisory, one support case, and one paid order→statement→dual-approved payout reconciliation.

Use `/admin/v1/pilot/metrics` for retained counts and `/admin/v1/pilot/launch-assessment` for the mechanical gate. The assessment returns `NO_GO` until the minimum outcomes exist. Review time, defects, support burden, SDK gaps, incidents, withdrawal recovery, statement variance, and payout variance are reviewed weekly.

F-008 requires a human go/no-go record signed by Product, Platform, Security, Support, Finance, and Legal. Any unresolved high-risk finding is an automatic no-go. Tooling readiness or synthetic fixtures never count as invited publishers or pilot observation.
