- [~] **E-001** (BE/SEC) Customer identity, verified email, MFA, recovery, session rotation, audit — implemented in `apps/marketplace-api`: scrypt password hashing, TOTP MFA (verified against the real RFC 4226/6238 known-answer vectors, not just round-tripped) with hashed single-use recovery codes, opaque session tokens hashed at rest with rotation and reuse-detection (presenting an already-rotated token revokes every session on the account — `RefreshToken`'s plaintext-storage/no-reuse-detection gap is not repeated here), exponential lockout after repeated failures, and every identity event writes an audit row inside the same transaction as the mutation (31 passing tests: `identity-crypto.spec.ts`, `identity.service.spec.ts`).
