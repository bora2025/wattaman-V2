# Wattanam Learning

Official Learning plugin for courses, lessons, assignments, quizzes, interactive content,
engagement and course-session attendance. Version 0.1.3 establishes the complete namespaced data
foundation plus scoped course/assignment discovery, rich quiz authoring and attempts, enrollment,
and transaction-locked, answer-key-safe lesson and quiz players. Legacy routes remain authoritative
until parity, adoption, rollback and hosted lifecycle certification are complete.
