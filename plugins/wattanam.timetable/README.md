# Timetable plugin

This official plugin owns new timetable data in the `plugin_wattanam_timetable_` namespace. Version 0.1.4 contains document, subject, class, classroom, teacher, lesson, entry and teacher lesson-attendance tables; requires Academic Management for stable class identity; uses core-user directory identifiers with local display snapshots; provides permission-gated CRUD routes, collision-safe schedule generation with a non-mutating preview, declarative fallback pages, and the trusted rich timetable workspace shared with Wattanam core. The workspace provides the existing wizard, entity management, scheduling board, drag-and-drop entry editing, generation, printing and exports while sending timetable mutations exclusively through the plugin API.

The legacy `backend/src/timetable` service remains available during the rollback window. New plugin installations use plugin-owned tables and APIs. Existing schools still require the real-PostgreSQL adoption and reconciliation drill before legacy routes or tables can be retired. Teacher lesson-attendance belongs here; staff employment attendance remains Human Resources, student school-day attendance remains Attendance Manager, and course-session attendance remains Learning per ADR-0019.
