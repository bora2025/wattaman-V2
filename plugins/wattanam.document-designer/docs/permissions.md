# Permissions

| Permission | Purpose |
| --- | --- |
| `wattanam.document-designer.view` | Read templates and previews. |
| `wattanam.document-designer.edit` | Create, edit, activate and remove templates. |
| `wattanam.document-designer.generate` | Generate cards, certificates and QR assets (future workflow). |
| `wattanam.document-designer.print` | Print and export generated documents (future workflow). |

Generation does not grant unrestricted access to person records. The generation workflow must
consume authorized Academic/HR read contracts and retain their row-scope decisions. Registering
the latter two permissions does not make the generation or printing workflows complete.
