# Wattanam Finance

Version 0.1.1 owns school operational fees, immutable receipts, compensating payment reversals,
invoice settings and privacy-minimized student balance projections. Platform subscription billing
remains a separate core/marketplace concern.

Official student fee, immutable receipt and finance reporting plugin. Money is stored only as integer
minor units with an explicit ISO currency. Student eligibility is resolved through the Academic
Directory contract; the plugin never joins Academic tables.
